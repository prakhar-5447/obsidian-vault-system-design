# Redis

## What is Redis?

In-memory data store commonly used for low-latency caching and other fast data operations.

## Common Uses

- Caching
- Sessions
- Rate limiting
- Distributed locks
- Counters
- Pub/Sub

## Data Structures

- String
- Hash
- List
- Set
- Sorted Set
