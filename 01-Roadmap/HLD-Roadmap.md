# HLD Roadmap

## Interview Design Framework

1. Clarify requirements
2. Define functional requirements
3. Define non-functional requirements
4. Estimate scale
5. Define APIs
6. Model data
7. Draw high-level architecture
8. Identify bottlenecks
9. Scale the system
10. Design failure handling
11. Deep dive into the hardest component
12. Explain trade-offs
